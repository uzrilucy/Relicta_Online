# 렐릭타 온라인 공식 홈페이지

현재 배포 파일 버전: **v1.3.0** · 안내 기준 봇 카드 v0.8.7 · 확장 Relicta Session v0.8.13

풀다이브 VRMMORPG 시뮬레이션 봇 《렐릭타 온라인》의 설정집입니다.
게임 서비스 공식 홈페이지 형식으로 만들었습니다.

빌드 과정이 없는 정적 사이트입니다. 이 폴더를 그대로 GitHub Pages에 올리면 됩니다.

## 폴더 구조

```
index.html            페이지 본문
assets/css/style.css  디자인
assets/js/data.js     공개 데이터(인물 162명, 길드, 소속)
assets/js/profiles.js 인물 상세 프로필(공개 항목)
assets/js/nai.js      인물별 NAI 캐릭터 태그
assets/js/sealed.js   봉인 문서와 인물별 봉인 기록(스포일러)을 인코딩한 꾸러미
assets/js/app.js      동작 스크립트(필터, 모달, 지도, 랭킹, 봉인 해제)
img/                  인물 이미지 (cXXX_h 얼굴 / cXXX_f 전신 / cXXXr 플레이어의 현실 모습 / cXXXa 아바타·신의 형상)
emblem/               길드 엠블럼 12종 (SVG)
promo/                로고, 커버, 스틸컷, PV 영상
div/                  섹션 구분선 (SVG)
.nojekyll             GitHub Pages가 Jekyll 변환을 하지 않도록 하는 빈 파일
```

## GitHub Pages 배포

1. GitHub에서 새 저장소를 만듭니다. 예: `relicta-online`
   - 무료 계정에서는 저장소를 **Public**으로 만들어야 Pages가 켜집니다.
2. 이 폴더의 내용을 저장소 맨 위에 올립니다.
   - `index.html`이 저장소 최상단에 있어야 합니다.
   - 파일이 560개가 넘습니다. 웹 업로드는 한 번에 100개까지만 됩니다.
   - **GitHub Desktop**으로 올리면 한 번에 끝납니다.
     - 저장소를 Clone합니다.
     - 이 폴더 내용을 Clone한 폴더에 붙여 넣습니다.
     - Commit → Push 합니다.
   - 웹 업로드만 쓴다면 아래처럼 나눠 올립니다.
     - ① `img` 외 전부
     - ② `img` 절반씩 두세 번
   - 숨김 파일(`.nojekyll`, `.gitattributes`)은 빠지기 쉬우니 함께 올라갔는지 확인하세요.
3. 저장소의 **Settings → Pages**로 갑니다.
   - **Source**를 `Deploy from a branch`로 둡니다.
   - Branch를 `main`, 폴더를 `/ (root)`로 고르고 Save를 누릅니다.
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소명>/`에서 열립니다.

### 배포 후 하면 좋은 것

`index.html`의 공유 카드 이미지는 지금 상대 경로입니다.
디스코드나 트위터 미리보기에 이미지가 뜨게 하려면 전체 주소로 바꾸세요.

```html
<meta property="og:image" content="https://<아이디>.github.io/<저장소명>/promo/cover-logo-a.jpg">
```

## 봉인 문서에 대해

봉인 문서, 히든 인물 3명, 인물마다의 봉인 기록(심층 코어·그림자·서사 떡밥 등)은 `assets/js/sealed.js`에 인코딩되어 있습니다.
봉인 문서는 **봉인 해제** 버튼을, 인물 봉인 기록은 인물 파일의 **열람** 버튼을 눌러야 나타납니다.
페이지 소스를 열어 봐도 스포일러가 바로 보이지 않게 하려는 장치입니다. 보안 잠금은 아닙니다.

봉인 문서나 인물 데이터를 고친 뒤에는 원본 소스 꾸러미(`relicta-site-source`)의 `pack.py`로 다시 만들어야 합니다. 원본 꾸러미에는 스포일러가 평문으로 들어 있으니 **저장소에 올리지 마세요.**

## 수정 팁

- 모든 텍스트 파일은 **UTF-8(BOM 없음)**입니다.
  - 메모장이나 VS Code에서 저장할 때 인코딩이 바뀌지 않게 주의하세요.
  - `.editorconfig`와 `.gitattributes`가 대부분의 편집기와 Git에서 이를 지켜 줍니다.
- 인물 이미지를 바꿀 때는 같은 파일명으로 덮어쓰면 됩니다.
  - `_h`: 얼굴, 정사각 320px
  - `_f`: 전신, 투명 배경, 세로 560px
- 외부 리소스는 Google Fonts뿐입니다. 나머지는 전부 이 폴더 안에 있습니다.

## v1.2.0 · 성능 개선

### 원인과 수정

- 별 배경이 화면 해상도에 비례해 별 개수를 늘리고 매 프레임 전체 캔버스를 다시 그렸습니다. 이제 별 장식은 한 번 그린 뒤 유지하고 화면 크기가 달라질 때만 다시 그립니다. 내부 해상도와 별 개수에 상한을 두었습니다.
- 전체 화면 모달과 고정 목차·하단 메뉴의 배경 흐림 효과를 줄였습니다. 1100px 이하에서는 상단 메뉴 흐림과 큰 캐릭터 이미지의 그림자 필터도 제거했습니다.
- 화면 밖 지도·장식 애니메이션, 백그라운드 탭, 상세창 뒤쪽 효과는 일시 정지합니다. 접속자 숫자도 보이는 동안에만 갱신합니다.
- 하단 이미지에 지연 로딩과 비동기 디코딩을 적용하고, PV는 재생 전 미리 다운로드하지 않도록 했습니다. 재생 중인 PV는 화면 밖이나 백그라운드, 상세창 뒤로 가면 일시 정지합니다.
- 약 379KB인 `sealed.js`는 봉인 문서를 실제로 열 때 한 번 불러옵니다. 연결 오류 시 재시도할 수 있고, 이전 열람 상태도 복원합니다.
- CSS·JS 버전 주소와 푸터 표시를 `v1.2.0`으로 올렸습니다.

### 적용 파일

v1.1.0이 적용된 저장소에서는 다음 세 파일을 함께 교체하세요.

## v1.2.1 · 봉인 기록·관계 링크 수정

이 대화에서 제작한 v1.2.0을 바탕으로 갱신했습니다. 인계 패키지에 포함된 구형 사이트로 재생성하지 않았습니다.

- 통신 실패 안내와 다시 불러오기 버튼을 추가했습니다.
- 메이블 헤이즈 → 메이블, 바솔로뮤 브루어·바트 → 바솔로뮤로 관계 링크를 연결했습니다. 설정 본문은 변경하지 않았습니다.
- 리소스 주소와 푸터의 버전을 v1.2.1로 올렸습니다.
